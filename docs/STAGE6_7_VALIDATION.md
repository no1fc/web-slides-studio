# 6·7단계 검증 결과 — 2026-10-21

서비스가 생성한 합성 자료를 실제 Windows Microsoft PowerPoint로 열고 편집·저장·재열기했다. OOXML 검사나 미리보기만으로 편집성을 판정하지 않았다. 운영 서버와 사용자 발표 파일은 이번 검사 대상에 포함하지 않았다.

## 실행 환경과 실제 편집

- Node.js 22.14.0, Chrome 156.0.8078.47, PptxGenJS 4.0.1.
- Microsoft PowerPoint 16.0, Build 20430. 차트 데이터 편집은 설치된 Excel 워크북을 이용했다.
- 테스트 자료: 16:9 두 장, 1920×1080 브라우저 / 960×540pt PowerPoint. 한글·Unicode·리치 텍스트·회전 도형·자르기 이미지·그룹 자식·겹침·노트·테마·표·막대/꺾은선/원형 차트 포함.
- 생성 파일 SHA-256: `52f84d8cf2980e0f640369a076aed093438fc1fbdddaee12925dac5e0b44d406`.
- 실제 앱 검사: **49/49 통과**, 오류 0. 검사 스크립트는 입력 경로·생성 매니페스트·해시를 확인하고 복사본만 수정한다.

| 검사 | 결과 |
| --- | --- |
| 네이티브 개체 인식 | 텍스트 5개, 도형 5개, 자르기 이미지 1개, 표 1개, 차트 3개 |

## 외형 비교와 보완

PowerPoint의 PNG 출력과 브라우저 캡처를 모두 1920×1080으로 비교하고 나란히 배치한 이미지도 확인했다. 누적 문단 줄간격 차이, 점선에 의해 끊기던 화살촉, 차트 정수 뒤의 불필요한 소수점 표기를 수정했다. 실제 표시 줄간격은 정규화된 편집 상태와 분리해 PPTX 측정 메타데이터로 전달하여 텍스트가 계속 네이티브로 출력되는지도 검사했다.

| 진단 항목 | 보완 전 | 보완 후 |
| --- | ---: | ---: |
| 슬라이드 1 RGB 평균 절대차, 0~255 | 2.332518 | 1.968197 |
| 슬라이드 2 RGB 평균 절대차, 0~255 | 2.210390 | 2.193734 |
| 슬라이드 1 최대 채널 차이가 24 초과인 픽셀 비율 | 1.843991% | 1.658951% |
| 슬라이드 2 최대 채널 차이가 24 초과인 픽셀 비율 | 2.048611% | 2.040123% |
| 리치 텍스트 영역 RGB 평균 절대차 | 12.325529 | 9.506978 |

픽셀 수치는 렌더러 간 차이를 찾기 위한 진단값이다. 호환성 백분율이나 통과 기준으로 해석하면 안 된다. 전체 평균은 작은 영역의 중요한 차이를 숨길 수 있으므로 개체 영역별 수치와 이미지를 함께 확인했다. 글꼴 래스터화·목록 여백·밑줄·차트 축/범례 위치 등의 미세한 차이는 남아 있다. 다른 글꼴, Office 버전, macOS/Web PowerPoint 및 실제 사용자 자료의 외형까지 보장하지 않는다.

## 회귀 검사와 독립 검토

최종 `npm test`는 **264/264 통과**, 실패·취소·생략 0, 종료 코드 0이었다(약 129초). 전체 테스트는 브라우저 동시 실행 부하를 제한하기 위해 `--test-concurrency=2`로 실행한다. `test:e2e`에 지정된 파일도 전체 `npm test`에 포함된다.

- 모델·상태: 표/차트 유효성·보안·크기 제한, 이전 최대 크기 상태의 기본 효과 필드 보완.
- 브라우저: 작성·수정·선택·복제·Undo·저장·재접속, quoted TSV의 탭/줄바꿈, 적용 중 대화상자 잠금, 슬라이드 복제 효과와 정적 출력, 그룹 효과 유지 및 혼합 효과 거부.
- 출력: 네이티브 표/차트 데이터, 고유 개체 ID와 효과 대상, 그림 배경 효과, 측정 줄간격과 잘리는 표의 배경 보존, 오프라인 자산.
- 가져오기: ZIP 경로·중복·CRC·용량, 엄격 XML과 외부 관계, 이미지 마스크 경고, 2장 이동/크기, 보고서 확인 전 자료 미생성.
- 독립 코드 검토에서 지적한 이미지 마스크 표현 손실 경고와 그림 배경 효과 대상 누락을 수정했다. 재검토 범위에서 남은 P1/P2 지적은 없었다.
