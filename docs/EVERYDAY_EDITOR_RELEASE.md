# 일반 사용자 발표 편집기 업데이트

2026-10-23. 기존 바닐라 JavaScript/Node 서버, 불변 저장 이력, HTML 자산과 MCP 설치기를 확장했다.

| --- | --- |

## 호환성

기존 자료/개체 ID/원본 자산/버전 파일을 일괄 변환하거나 삭제하지 않는다. 이전 공유 링크는 재게시 전까지 이전 노트 정책을 유지한다. 재게시하면 새 노트 설정이 같은 링크에 반영되고 암호 접근 세션은 만료된다. 암호를 비워 두면 기존 암호를 유지하며 명시적 해제 선택으로만 없앤다.

MCP의 기존 직접 저장 도구는 호환성을 위해 유지한다. 새 권장 제작 흐름과 복사용 프롬프트는 변경안 제출 도구를 사용한다. 기존 AI 클라이언트는 업데이트 후 완전히 종료·재시작해야 한다. 웹 서버나 Docker를 외부 PC에 새로 설치할 필요는 없다.

SHA-256 업로드 키를 재시도에 사용하여 응답을 잃은 성공 요청을 반복해도 새 자료를 만들지 않는다. 같은 파일의 별도 사본이 필요하면 자료실의 복제를 사용한다. 서버의 ZIP 경로/심볼릭 링크/실제 해제량 제한은 그대로 적용한다.

## 배포 및 복구

1. 기존 데이터 경로와 이미지 태그를 보존하고, 해당 인스턴스의 운영 지침을 따른다.
2. `npm test`, `npm run test:mcp`와 Windows/Linux CI 결과를 확인한다.
3. 공개 소스만 Docker 빌드 컨텍스트로 사용한다. 운영 data와 환경·인증 파일은 포함하지 않는다.
4. 대상 studio 서비스만 짧게 정지하고 data 전체를 비공개 백업한다. 같은 데이터 마운트로 새 이미지의 해당 서비스만 시작한다. 다른 서비스/DB/nginx를 중지하지 않는다.
5. health, 로그인 이전 API 차단, 정적 파일 해시, 브라우저 오류, 기존 데이터 파일 보존과 다른 컨테이너 ID를 확인한다.

**새 만료·암호 공유가 생성된 뒤에는 구버전 이미지로 단순 롤백하지 않는다.** 구버전은 새 접근 정책을 해석하지 못한다. 데이터를 보존하고 호환되는 수정 이미지를 배포한다. 백업 복원은 그 이후 편집을 잃을 수 있으므로 별도 검토가 필요하다. 앱 재시작 시 관리 세션은 만료되어 다시 로그인해야 한다.

## 검증 범위와 한계

자동 검사는 임시 데이터·합성 암호·실제 Chromium 및 표준 MCP 클라이언트로 수행한다. 기존 운영 자료 7개와 저장 이력 11개는 읽기 전용 호환성을 확인했다. 활성 자료 1개는 비공개 임시 복사본에서 실제 브라우저로 편집·저장·새로고침·원래 버전 복원을 확인했으며, 휴지통 자료 6개는 편집 검사에서 제외했다. 원본 파일 224개의 내용 해시는 유지됐다. 노트가 들어 있는 복잡한 정규식은 내용을 임의로 바꾸지 않고 공유/내보내기를 거부하여 수정 방법을 안내한다. 코드가 동적으로 조합하거나 암호화한 임의 정보의 의미까지 노트로 식별하지는 않는다. 다른 PC의 글꼴, 실제 PowerPoint 출력 차이, 다중 모니터 하드웨어와 Safari는 수동 확인 대상이다.

검사 수·커밋·배포 결과는 최종 변경 이력 및 인스턴스 운영 기록에 남긴다. 운영 계정·개인 발표 내용·스크린샷은 공개 저장소에 넣지 않는다.
