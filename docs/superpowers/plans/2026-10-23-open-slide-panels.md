# open-slide 패널 기능 보완과 노트 공유 수정

사용자가 open-slide 패널을 확인해 없는 기능을 적용하고, 발표자 노트 공유 선택이 작동하지 않는 오류를 수정하도록 요청했다. 기존 저장·충돌·공유·출력 구조를 재사용한다.

1. 고정 참조 커밋의 inspector/arrange/style/assets 소스를 REA로 확인하고 기존 기능과 대조한다.
2. 노트 포함 선택 유지와 명시적으로 포함한 공유본의 노트 열람을 구현한다. 청중 화면 및 제외 응답은 계속 노트를 제거한다.
3. 부분 글자 굵기·간격, 정렬 기준·안내선·부모 선택, 시각적 자르기를 기존 편집 트랜잭션에 연결한다.
4. 비공개 자료별/공용 자산 보관함을 추가한다. 복사는 독립 자산이며 기존 revision 참조 파일을 보호한다. SVG와 글꼴은 별도 검증하고 외부 검색은 관리자 브라우저에서만 수행한다.
5. 전체 디자인을 별도 임시 미리보기로 제공한다. 적용 전 저장하지 않고, 취소/로컬 실행 취소 및 기존 revision 저장·복원을 사용한다.
6. 회귀·실제 브라우저·운영 제한 Docker·기존 자료 사본·Windows/Linux MCP CI를 확인한다. 코드 검증 후 GitHub에 반영하고 studio 서비스만 백업 후 갱신한다.

구현 경계: 공용 자산은 인증된 관리자 전용이다. 가져온 폰트의 자동 적용이나 서버 인터넷 프록시는 추가하지 않는다. 참조에 없는 임의 필터/3D 편집도 추가하지 않는다. 운영 비밀번호와 실제 자료를 바꾸지 않는다.
