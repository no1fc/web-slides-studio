# open-slide 편집 화면 일치 구현 계획

**승인된 방향:** 사용자가 ‘open-slide 화면을 최대한 동일하게’를 선택했다. 이전 일반 사용자 기능·저장·공유·배포 요청을 이어간다.
**목표:** open-slide commit 1f18ab5의 DEV 편집 화면을 실제 실행하여 구조·색·치수·상태를 비교하고 기존 SDLAB 편집기에 적용한다.
**구조:** 기존 DOM/클릭·저장 함수를 재사용하는 editor-shell.js와 편집 화면에만 적용하는 CSS. 단일48px헤더·중앙제목·264px세로목록·320px선택패널·40px캔버스여백·전체하단36px노트. 큰 리본은 편집 도구로 접어 보존한다. 무채색과주홍 강조·Lucide아이콘·로컬Geist를 사용하며 라이선스를 함께 배포한다.
**스택:** 기존 vanilla JavaScript/Node/Playwright, 추가 런타임 의존성 없음.

## 보호 범위

- 기존 데이터/revision/자료ID/링크/내보내기/자동저장과 충돌검사를 변경하지 않는다.
- 접근 가능한 버튼 이름·Tab·IME·Undo/Redo·표차트·AI 수정 요청을 유지한다.
- 기술 기능과 기존 메뉴는 편집 도구/고급 경로로 모두 접근 가능해야 한다.
- 실제 기능이 없는 UI는 만들지 않는다. 원본의 수동저장 표시를 SDLAB 자동저장에 맞게 조정한다.
- 참조 앱은 /tmp의별도 사본·임시 loopback 컨테이너에서만 실행한다.
