# Stage 3 Text Editing Implementation Plan

> **For agentic workers:** Use focused independent workers for the shared model, parent controls and PPTX output; coordinator owns bridge/editor integration. Run a fresh-context whole-change review before publication.

**Goal:** 텍스트 전체·부분 서식, 문단·상자 편집과 저장·출력을 구현하고 검증 후 GitHub main에 업로드한다.

**Architecture:** 공유 text 모델이 검증/DOM을 정의하고 browser editor가 선택과 IME·자동 맞춤을 담당한다. 부모는 UI/history, exporter는 구조화한 텍스트를 PPTX run으로 변환한다.

**Tech Stack:** 기존 Node/plain JavaScript/Playwright/PptxGenJS 4.0.1. 신규 의존성 없음.

**Spec:** ../specs/2026-10-21-stage3-text-design.md

## Global Constraints

schemaVersion1 하위호환, 기존 2MB 제한, origin/session/잠금/저장 충돌 보호 유지. 공개 저장소에 운영 데이터·인증·내부 조사문서를 추가하지 않는다. main 강제 덮어쓰기 금지.

## Review Focus

- 문자 범위가 toolbar 이동/한글 조합/저장 때문에 다른 개체에 적용되지 않는가.
- richText와 기존 text patch 충돌 및 이전 서식이 복원·복제에서 유실되지 않는가.
- 빈 문단·목록·emoji offset이 DOM과 모델에서 일치하는가.
- 자동 맞춤·세로정렬이 개체 좌표·크기를 바꾸거나 저장 글자 크기를 파괴하지 않는가.
- PPTX에 실제 run/문단 속성이 기록되며 지원 불가 HTML은 일관되게 보존되는가.
