# 1단계: 단일 개체 정밀 편집

사용자가 승인한 로드맵 순서에 따라 0단계 다음의 단일 개체 편집을 구현한다. 실제 Linux 서버에는 배포하지 않는다.

- 8개 크기 핸들과 회전 핸들. 반대쪽 변/모서리를 고정한다. Shift는 비율 유지, Alt는 중심 기준, Shift+회전은 15도 간격이다.
- 비율 유지 체크박스는 크기 핸들과 너비/높이 수치 입력에 공통 적용한다. 선택 변경 시 해제하며 문서에 저장하지 않는다.
- 방향키는 문서 좌표 1px, Shift+방향키는 10px. 누르고 있는 동안 반복 이동은 한 번의 Undo로 확정한다. 텍스트·폼·IME 조합 중에는 개체 명령을 실행하지 않는다.
- 화면 맞춤과 25/50/75/100/150/200% 배율. 100%는 1920×1080 문서의 1px=화면 1px이다. 큰 화면은 캔버스 영역에서 스크롤한다. 배율을 저장 상태/내보내기/Undo에 넣지 않는다.
- 크기·회전·이동은 프리뷰 뒤 한 번만 확정한다. Escape, 포인터 취소/캡처 상실/창 이탈, 슬라이드 전환 시 미완료 포인터 동작을 원복한다.
- 크기값은 기존 CSS width/height 의미를 유지한다. content-box의 padding/border와 회전된 개체의 실제 크기를 구분한다.
- 기본 HTML/추가 개체와 CSS rotate를 지원한다. transform/skew/3D/비균일 조상 변환 및 inline 다중 줄 개체는 정밀 핸들을 숨기고 속성 패널에 이유를 알린다. 원본 HTML을 임의로 재작성하지 않는다.
- 스키마 version 1, 런타임 의존성 변경 없음. HTML/PDF 외형과 저장 왕복을 검증한다. 편집형 PPTX의 기존 회전 외접 사각형 추출 한계는 별도 명시한다.

완료 기준: 50/100/200%에서 동일 문서 좌표, 회전/비율/중심 크기 조절, 입력 보호, 한 동작 한 Undo, 취소 원복, 저장 재열기 및 0단계 회귀 통과. Linux 적용용 패치와 검증 절차를 전달한다.
