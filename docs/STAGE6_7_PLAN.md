# 6·7단계: PowerPoint 호환성과 작성 확장

사용자가 구현, 실제 PowerPoint 검증, 테스트 후 main 게시를 승인했다. 운영 Linux 배포는 사용자가 수행한다.

## 계약

- 6단계는 설치된 Microsoft PowerPoint로 실제 서비스가 내보낸 PPTX를 열고, 텍스트·위치·도형·표 셀·차트 데이터를 수정하고 별도 파일로 저장한 후 다시 읽는다. 슬라이드를 PNG로 내보내 브라우저 원본과 외형을 비교한다. 검사 프로그램, 결과, 지원 범위와 한계를 기록한다. 원래 사용자 파일에는 접근하지 않는다.
- 7단계의 제한적 PPTX 가져오기는 16:9 자료의 직접 배치된 텍스트, 기본 도형, PNG/JPEG/GIF 이미지, 단순 표, 막대/꺾은선/원형 차트와 노트를 대상으로 한다. 지원하지 않는 서식/마스터/그룹/효과는 경고로 보고한다. 무손실 왕복 변환을 주장하지 않는다. 읽기 전용 미리보기 보고서를 먼저 보여주고 사용자가 가져오기 버튼을 누른 경우 자료를 생성한다. ZIP/XML 자원 제한과 경로·외부 관계 검증을 적용한다.
- 표 객체는 `kind: table`, `table: { rows: string[][], header: boolean, fontSize, color, fill, headerFill, border }`이다. 1~20행, 1~10열, 셀당 2,000자, 동일 열 개수. 전체 표에 균일한 행 높이와 열 너비, 일반 텍스트 셀을 지원한다.
- 차트 객체는 `kind: chart`, `chart: { type: bar|line|pie, categories: string[], series: {name, values:number[]}[], colors: string[], fontSize }`이다. 최대 20범주/5계열, 원형은 1계열과 음이 아닌 값(합계 양수), 값은 유한수 ±1e9. 웹에서는 SVG, PPTX에서는 데이터가 포함된 네이티브 차트로 출력한다.
- 표/차트 데이터는 대화상자에서 수정하며 JSON 편집에도 같은 검증을 적용한다. 이동·크기·복제·정렬·레이어·저장·실행 취소를 지원한다. 이번 범위에서 표/차트 그룹화와 회전은 거부한다.
- `transitions`: 슬라이드 ID → `none|fade|push`, `animations`: 추가 객체 ID → `none|appear|fade`. 화면 진입 시 전체 객체 효과를 함께 재생하는 기본 효과다. 편집/썸네일/PDF/PPTX 정적 캡처에서는 효과를 멈춘다. PPTX는 슬라이드 전환과 지원 객체의 진입 효과를 기록하며 네이티브로 변환하지 못한 객체 효과는 내보내기 경고 대상이다.
- 누락된 새 필드는 기본값으로 읽고 기존 버전·노트·템플릿을 보존한다. UI/JSON/가져오기/저장에 동일한 모델 검증을 사용한다.

## 작업 계획

**Goal:** 실제 PowerPoint 검증 가능한 내보내기와 제한적 가져오기·표·차트·기본 효과를 완성한다.

**Architecture:** 기존 저장 모델, 격리된 콘텐츠 iframe, PptxGenJS를 유지한다. 공유 `SDData` 모델/렌더러와 네이티브 출력 모듈, 제한적 OOXML 파서를 분리한다. 외부 네트워크나 Office가 Linux 서비스의 필수 의존성이 되지 않는다.

**Tech Stack:** Node.js, 기존 Playwright/linkedom/JSZip/PptxGenJS, Windows PowerPoint COM.

1. 계약 독립 검토 후 모델·출력과 가져오기 파서를 병렬 구현한다. 각각 실패하는 핵심 테스트부터 작성한다.
2. 주 작업자는 상태 검증/렌더/브리지/UI/서버를 연결하고 기본 효과를 구현한다. 독립 파일 소유권을 지킨다.
3. 실제 PowerPoint 검사 도구와 재현 자료를 만들고, 내보내기 → 실제 앱 수정/저장 → 다시 읽기를 확인한다. 확인한 호환성 문제를 수정하고 회귀 테스트를 추가한다.
4. 제한/보안/단위 테스트와 브라우저 작성·저장·가져오기·효과 테스트를 실행한다. 전체 테스트 동시성은 2, PowerPoint 작업은 하나씩 실행한다.
5. 독립 코드 검토, 배포·검증 문서 작성, 전체 테스트 후 같은 트리를 GitHub main에 게시하고 원격 해시를 검증한다.
