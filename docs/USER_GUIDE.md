# 사용 안내

## 1. 자료 등록

HTML 발표를 `index.html`과 관련 자산 폴더로 준비합니다. 폴더 구조를 유지한 채 ZIP으로 묶거나, 자료실의 폴더 선택으로 올립니다. ZIP 안에 단일 상위 폴더가 있어도 그 안의 index.html을 찾습니다. 여러 index.html 중 진입점을 결정할 수 없으면 오류를 표시합니다.

외부 URL을 참조하는 이미지·글꼴·라이브러리는 파일로 포함하고 상대 경로로 바꾸세요. ZIP 내부의 서버 환경파일, 심볼릭 링크, 경로 탈출 항목은 사용하지 않습니다. PDF/PPTX 원본을 올려 웹 편집하는 서비스는 아닙니다.

등록한 자료는 비공개입니다. 등록 버튼을 누르는 것만으로 공개 링크가 생기지 않습니다.

## 2. 자료실 정리

- 제목 또는 폴더 이름으로 검색할 수 있습니다.
- 자료 카드의 ‘폴더’에서 분류명을 입력합니다. 해당 폴더는 사이드바에 표시됩니다.
- ‘복제’는 자산과 저장 이력을 독립 자료로 복사하고 새 미리보기 권한을 만듭니다. 공유 상태는 복사하지 않습니다.
- ‘휴지통’은 자료를 숨기고 기존 공유를 종료합니다. 휴지통에서 복원할 수 있습니다.
- ‘완전 삭제’는 확인 후 자료의 서버 파일과 이력을 제거합니다. 복원 버튼으로 되돌릴 수 없습니다. 별도 백업이 있다면 서버 관리자가 복구해야 합니다.

## 3. 편집과 저장

자료 카드를 누르면 편집기가 열립니다. 왼쪽은 슬라이드 순서, 가운데는 발표 화면, 오른쪽은 선택 요소의 편집 속성입니다.

글이나 이미지를 선택하고 드래그하거나 오른쪽 수치를 입력해 위치·크기를 조절합니다. 글은 더블클릭하거나 ‘내용’ 입력란에서 수정합니다. 글 전체를 바꾸면 원래 글 안의 부분 강조·색상 같은 서식이 사라질 수 있습니다.

글·이미지·도형을 새로 추가할 수 있습니다. 가져온 모든 HTML 컨테이너를 일반 그래픽 편집기처럼 조작할 수 있는 것은 아닙니다. 원본이 제공하는 Three.js 배경은 유지하며, 배경 표시 여부와 `data-scene` 장면을 선택할 수 있습니다.

자동 저장 후 상단 ‘저장됨 · v번호’를 확인합니다. 브라우저를 닫기 전에 저장 상태를 확인하세요. 실행 취소·다시 실행은 현재 편집 세션에서 사용하며, 오래된 내용은 ‘버전’에서 복원합니다. 복원은 과거 파일을 덮어쓰는 대신 새 revision을 만듭니다.

## 4. 여러 창에서 수정했을 때

동시 공동 편집은 지원하지 않습니다. 다른 창이 먼저 저장하면 충돌을 알립니다. 내 수정 내용을 JSON으로 내려받거나, 내 수정으로 새 버전을 저장하거나, 서버의 최신 내용을 다시 열 수 있습니다. 내 내용으로 저장하면 다른 창의 최신 수정이 현재 화면에서 대체될 수 있지만 기존 revision은 남습니다.

## 5. 파일 관리

자료 카드 또는 편집기에서 ‘파일 관리’를 엽니다. 목록은 서버에 실제 보관 중인 웹 자산이며 ZIP 파일 자체는 남지 않습니다. 용량은 파일 본문·revision·메타데이터 크기의 합이며 디스크 블록 점유량이나 컨테이너 로그 용량은 포함하지 않습니다.

각 파일을 다운로드하거나 전체 웹 원본을 ZIP으로 받을 수 있습니다. 원본 묶음에는 편집 결과가 적용되지 않습니다. 수정된 발표를 내려받을 때는 ‘다운로드 → HTML ZIP’을 사용하세요. 원본 HTML에는 편집용 식별자가 추가되어 최초 파일과 바이트 단위로 같지 않을 수 있습니다.

삭제 버튼은 시스템이 추가 이미지로 기록한 파일 중 사용 참조가 없는 파일에만 활성화됩니다. 원본 파일, 기능 도입 이전 파일, 어느 revision에서든 참조하는 파일은 보호됩니다. 파일을 삭제하기 위해 이전 버전을 임의로 버리지는 않습니다. 큰 자료 전체가 불필요하면 휴지통에서 자료 단위로 완전 삭제하세요.

## 6. 발표와 공유

‘발표’는 현재 저장 내용을 새 창의 비공개 미리보기로 엽니다. ‘공유’는 현재 저장 버전을 게시합니다. 공개 링크를 가진 사람은 누구나 열 수 있으므로 전달 대상을 확인하세요.

공유 후 다시 수정해도 이미 게시한 버전은 그대로입니다. 최신 내용을 공개하려면 다시 게시합니다. ‘공유 종료’나 자료의 휴지통 이동은 기존 링크를 무효화합니다. 상대가 이미 내려받거나 캡처한 파일은 회수하지 못합니다.

## 7. 다운로드

HTML은 웹 기능을 최대한 유지합니다. PDF/PPTX는 출력 시점의 정지 화면을 사용합니다. 원본이 fetch, ES module 같은 HTTP 기능을 쓰면 내려받은 ZIP을 파일 더블클릭으로 열기보다 로컬 HTTP 서버에서 여세요. 단순 예제는 index.html만 열어도 사용할 수 있습니다.

출력은 서버당 한 번에 하나만 실행합니다. 다른 작업 중이면 완료 후 다시 시도하라는 안내가 나옵니다. 출력 결과는 30분 후 만료하므로 필요한 파일을 내려받으세요.

## 8. 암호 변경

상단 ‘비밀번호 변경’에서 현재 암호와 새 암호를 입력합니다. 새 암호는 12~128자이며 확인값과 같아야 합니다. 성공하면 현재 창은 로그인 상태를 유지하고 다른 로그인 세션은 종료됩니다. 로컬 무인증 모드에서는 이 버튼을 표시하지 않으므로 서버 환경변수로 초기 암호부터 설정하세요.

## 자주 묻는 질문

**원본 ZIP이 계속 서버에 쌓이나요?** 아니요. 압축 해제 파일과 수정 이력이 쌓입니다. 파일 관리의 용량과 전체 자료 수를 함께 확인하세요.

**이전 버전을 지우면 공간이 줄어드나요?** 현재는 revision 개별 삭제 기능이 없습니다. 복원 가능성을 위해 이력을 유지합니다. 필요 없는 자료 전체를 완전 삭제할 수 있습니다.

**PPTX를 PowerPoint에서 모두 편집할 수 있나요?** 지원하는 글·이미지는 분리하지만 CSS·3D·복잡한 장식은 배경으로 합칩니다. 외형 보존 모드는 전체가 이미지입니다.

**자동 백업되나요?** 기본 제공하지 않습니다. 서버 운영자가 별도로 설정해야 합니다.
