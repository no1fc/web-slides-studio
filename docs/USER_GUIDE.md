> 앱의 로그인 화면과 상단 **사용 설명서**에서 `/help.html`을 새 탭으로 열 수 있습니다. 빠른 시작, 지원 파일 표, 출력 방식과 문제 해결을 함께 안내합니다.
> AI에 전달할 복사 프롬프트, Three.js 작성 조건, Codex·Claude Code 스킬/MCP 설치는 [AI 작성 안내](AI_AUTHORING.md)를 참고하세요.

# 사용 안내

## 코드 편집과 공통 마스터

파일 → 고급 도구의 **HTML/CSS**에서 현재 슬라이드 내부 구성과 추가 CSS를 편집합니다. 표지·제목과 본문·2단 비교 구성을 생성할 수 있습니다. **검증하고 적용**하면 새 버전에 저장됩니다. 원본·코드 개체의 기존 수정값은 초기화하고, 따로 추가한 글·이미지는 유지합니다. Undo와 버전 복원으로 되돌릴 수 있습니다.

**JSON**에서는 전체 편집 상태를 직접 수정합니다. 문법·스키마 오류는 입력을 유지한 채 표시합니다. 저장에 실패해도 수정창을 다시 열어 로컬 초안을 고칠 수 있습니다.

**마스터**에서는 공통 배경·로고·제목 영역을 HTML/CSS로 만들고 한 장 또는 전체 슬라이드에 연결합니다. 마스터를 수정하면 연결된 슬라이드에 함께 반영됩니다. 선택을 바꾸거나 창을 닫을 때 미적용 초안을 확인합니다.

코드·마스터는 원본 자산을 덮어쓰지 않고 저장 버전에 포함됩니다. 원본 ZIP과 현재 버전의 HTML 다운로드는 다릅니다. 마스터는 공통 장식 레이어이며, PowerPoint의 native 마스터/자리 표시자 편집 기능은 아직 아닙니다. 상세 지원 범위와 Linux 적용·검증은 [0단계 적용 안내](STAGE0_LINUX_DEPLOYMENT.md)를 참고하세요.

## 1. 자료 등록

HTML 발표를 `index.html`과 관련 자산 폴더로 준비합니다. 폴더 구조를 유지한 채 ZIP으로 묶거나, 자료실의 폴더 선택으로 올립니다. ZIP 안에 단일 상위 폴더가 있어도 그 안의 index.html을 찾습니다. 여러 index.html 중 진입점을 결정할 수 없으면 오류를 표시합니다.

외부 URL을 참조하는 이미지·글꼴·라이브러리는 파일로 포함하고 상대 경로로 바꾸세요. ZIP 내부의 서버 환경파일, 심볼릭 링크, 경로 탈출 항목은 사용하지 않습니다. PDF·구형 PPT·PPTM·DOCX·HWP·KEY는 가져올 수 없습니다. PPTX는 자료실의 **PPTX 가져오기**에서 지원되는 요소를 변환합니다. 16:9, 40 MiB, 압축 해제 64 MiB, 내부 ZIP 항목 2,000개, 1~80장, 편집 개체 500개 제한이며 변환 경고를 검토한 뒤 등록합니다.

등록한 자료는 비공개입니다. 등록 버튼을 누르는 것만으로 공개 링크가 생기지 않습니다.

## 2. 자료실 정리

- 제목 또는 폴더 이름으로 검색할 수 있습니다.
- 자료 카드의 ‘폴더’에서 분류명을 입력합니다. 해당 폴더는 사이드바에 표시됩니다.
- ‘복제’는 자산과 저장 이력을 독립 자료로 복사하고 새 미리보기 권한을 만듭니다. 공유 상태는 복사하지 않습니다.
- ‘휴지통’은 자료를 숨기고 기존 공유를 종료합니다. 휴지통에서 복원할 수 있습니다.
- ‘완전 삭제’는 확인 후 자료의 서버 파일과 이력을 제거합니다. 복원 버튼으로 되돌릴 수 없습니다. 별도 백업이 있다면 서버 관리자가 복구해야 합니다.

## 3. 편집과 저장

자료 카드를 누르면 편집기가 열립니다. 왼쪽은 슬라이드 순서, 가운데는 발표 화면, 위쪽은 한 줄의 제목·슬라이드·삽입·디자인·파일 메뉴와 발표·공유·다운로드 버튼입니다. 오른쪽은 **서식·배치·레이어** 패널입니다. 상단 **서식**으로 패널을 접거나 펼치며, 발표자 노트는 화면 전체 아래에서 엽니다.

글이나 이미지를 선택하고 드래그하거나 오른쪽 속성의 수치를 입력해 위치·크기를 조절합니다. 글은 더블클릭해 직접 입력하거나 상단 ‘내용 편집’ 창에서 바꿉니다. 부분 문구를 수정할 때는 더블클릭 후 해당 문자 범위를 선택하세요. ‘내용’은 전체 평문을 교체하므로 전체를 새 문구로 바꾸면 이전의 부분 서식 분포와 같지 않을 수 있습니다.

글·이미지·도형을 새로 추가할 수 있습니다. 가져온 모든 HTML 컨테이너를 일반 그래픽 편집기처럼 조작할 수 있는 것은 아닙니다. 원본이 제공하는 Three.js 배경은 유지하며, 배경 표시 여부와 `data-scene` 장면을 선택할 수 있습니다.

선택한 개체의 모서리·변 핸들을 당기면 크기가 바뀌고, 위쪽 둥근 핸들로 회전합니다. Shift는 비율 유지, Alt는 중심 기준 크기 조절이며 함께 사용할 수 있습니다. 회전 중 Shift를 누르면 15도 단위로 맞춥니다. ‘크기 비율 유지’ 체크는 숫자 너비/높이 입력에도 적용하며, 다른 개체를 선택하면 해제됩니다. 복잡한 CSS 변환 등 지원하지 않는 경우 속성 패널에 설명이 표시됩니다.

방향키는 1px, Shift+방향키는 10px 이동합니다. 키를 길게 눌러 이동한 결과는 한 번의 실행 취소로 되돌립니다. 글 편집·입력창·한글 조합 중에는 개체를 이동하지 않습니다. 드래그 도중 Escape 또는 창 이탈은 조작을 취소합니다.

캔버스에서 개체를 선택한 상태의 Tab·Shift+Tab은 보이고 잠기지 않은 다음·이전 개체를 선택합니다. 끝에 도달하면 선택을 해제하고 일반 포커스 이동으로 이어집니다. 입력창·글 편집 중과 편집기 메뉴에서는 기본 Tab 이동을 유지합니다.

캔버스 위 ‘배율’에서 화면 맞춤 또는 25~200%를 고릅니다. 100%는 1920×1080 문서를 실제 픽셀 크기로 표시하므로 화면보다 클 수 있습니다. 스크롤바·휠·트랙패드로 보이는 영역을 옮기며 Shift+휠은 가로 이동입니다. 배율 변경은 문서 크기·저장 내용·출력 크기에 영향을 주지 않습니다.

자동 저장 후 상단 ‘저장됨 · v번호’를 확인합니다. 브라우저를 닫기 전에 저장 상태를 확인하세요. 실행 취소·다시 실행은 현재 편집 세션에서 사용하며, 오래된 내용은 ‘버전’에서 복원합니다. 복원은 과거 파일을 덮어쓰는 대신 새 revision을 만듭니다.

### 텍스트 전체·부분 서식과 문단

오른쪽 **서식**에서 글꼴 이름, 글자 크기(6~400px), 색, **굵게·기울임·밑줄**을 바꿉니다. 숫자 굵기(300~800)와 글자 간격(−20~50px)도 선택한 문자에 적용합니다. 글꼴 이름을 입력하는 기능은 글꼴 설치 기능이 아닙니다. 브라우저에서 사용하는 글꼴은 PC에 설치하거나 발표의 로컬 글꼴 자산과 CSS로 준비하세요.

1. **전체 문자:** 개체를 한 번 클릭해 선택한 뒤 서식을 바꿉니다. 문자 편집 중에도 선택한 글자가 없이 커서만 있으면 문자 서식은 개체 전체에 적용됩니다.
2. **부분 문자:** 더블클릭하고 원하는 글자를 드래그해 선택한 뒤 오른쪽 도구를 누릅니다. 도구로 포커스가 옮겨져도 저장한 문자 범위에 적용합니다. 패널의 ‘선택한 문자와 문단에 적용’ 표시를 확인하세요.
3. **문단:** 개체만 선택하면 모든 문단에 적용합니다. 직접 입력 중에는 문자 선택 범위가 걸친 문단에, 커서만 있으면 현재 문단에 적용합니다.

문단 정렬은 왼쪽·가운데·오른쪽·양쪽입니다. 줄간격은 0.5~4배, 문단 뒤 간격은 0~200px이며 소수값도 입력할 수 있습니다. 들여쓰기·내어쓰기는 0~8단계로 조절하고 한 단계는 저장 문서 기준 32px입니다. 목록은 없음·글머리표·번호를 지원합니다. 번호는 들여쓰기 깊이별로 이어지며 같은 깊이에서 글머리표나 일반 문단으로 바꾸면 해당 깊이의 번호가 다시 시작합니다.

### 텍스트 상자와 자동 맞춤

**텍스트 서식 → 텍스트 상자**를 펼쳐 다음 값을 정합니다. 상자 설정은 문자 선택과 관계없이 개체 전체에 적용됩니다.

| 설정 | 동작 |
| --- | --- |
| 세로 정렬 | 상자 안에서 위·가운데·아래로 배치 |
| 넘치는 내용 → 표시 | 상자 밖으로 이어지는 텍스트도 표시 |
| 넘치는 내용 → 자르기 | 상자 경계 밖의 내용을 화면에서 가림. 저장한 문자는 유지 |
| 자동 맞춤 → 사용 안 함 | 저장한 크기를 그대로 표시 |
| 자동 맞춤 → 상자 안으로 글자 축소 | 상자 크기를 유지하고 글자·문단 간격·들여쓰기를 함께 줄여 표시 |

자동 맞춤은 저장된 글자 크기와 문단 값을 바꾸지 않습니다. 예를 들어 40px로 저장한 글자가 좁은 상자에서 작게 표시돼도 JSON의 크기는 40으로 유지됩니다. 최소 표시 글자 크기는 6px입니다. 그 크기에서도 맞지 않으면 넘침 안내가 남으므로 상자를 키우거나 내용·간격을 줄이세요. 캔버스 배율과 텍스트 자동 맞춤은 별개이며, 출력은 캔버스 확대율에 영향을 받지 않습니다.

### 입력·저장과 지원 범위

한글 조합 중 서식이나 저장 명령을 사용하면 조합 확정 후 처리합니다. 직접 글을 입력하는 동안 외부 클립보드에서 붙여넣은 내용은 **평문**으로 받아 외부 HTML·스타일을 가져오지 않습니다. 이는 아래의 앱 내부 개체 복사·붙여넣기와 별도의 동작입니다.

서식 명령 한 번은 Undo 한 번으로 되돌립니다. 저장·새로고침, 개체·슬라이드·자료 복제와 이전 버전 복원에 문자·문단·상자 서식이 포함됩니다. 한글 입력기의 조합과 포커스 이동은 운영체제에 따라 다를 수 있으므로 사용하는 환경에서도 확인하세요.

가져온 원본 텍스트는 편집할 때 기본 문자·문단 서식으로 구조화합니다. 이미지·표·다른 편집 ID가 포함된 복합 컨테이너, 잠긴 개체 또는 여러 개체 선택 상태에서는 텍스트 도구를 사용할 수 없습니다. 컨테이너 안의 편집 가능한 텍스트 하나를 선택하거나 잠금을 해제하세요. 고급 CSS 장식과 임의 HTML 구조 전체를 텍스트 모델로 재현하는 기능은 아닙니다. HTML/CSS·JSON·마스터 편집과 기존 배치 도구는 계속 사용할 수 있습니다.

### 여러 개체 선택과 이동

Shift, Ctrl 또는 Command를 누른 채 개체를 클릭하면 선택에 추가하거나 선택에서 뺍니다. 슬라이드의 빈 영역에서 드래그하면 사각형 안에 완전히 들어온 개체를 선택합니다. Ctrl+A 또는 Command+A는 현재 슬라이드에서 보이며 잠기지 않은 편집 개체를 모두 선택합니다. Escape, 빈 영역 클릭 또는 슬라이드 전환으로 선택을 해제합니다.

선택한 여러 개체를 드래그하거나 방향키로 함께 이동할 수 있습니다. 한 번의 이동·정렬·분배·숨기기는 실행 취소 한 번으로 전체를 되돌립니다. 드래그 도중 Escape로 취소하면 선택 개체 모두 원래 위치로 돌아갑니다. 다중 선택에서는 개별 크기·회전 핸들을 표시하지 않으므로 크기·회전·내용은 하나씩 선택해 바꾸세요. 텍스트 편집 중이나 입력창 안에서는 글 선택과 입력용 단축키가 우선합니다.

### 개체 복제와 복사·붙여넣기

오른쪽 **개체 배치 → 복제** 또는 Ctrl+D/Command+D로 선택한 개체의 독립 사본을 만듭니다. 사본은 오른쪽 아래로 24px 이동해 생성됩니다. 원본을 나중에 수정해도 사본의 내용과 서식은 함께 바뀌지 않습니다.

**복사** 또는 Ctrl+C/Command+C 후 같은 자료의 다른 슬라이드로 이동해 **붙여넣기** 또는 Ctrl+V/Command+V를 사용할 수 있습니다. 이 기능은 현재 앱의 같은 자료 안에서 사용하는 임시 복사 기능입니다. 운영체제 클립보드나 다른 자료·다른 프로그램과 연결되지 않으며, 새로고침 후 보관을 보장하지 않습니다.

기본 글·이미지·도형과 지원되는 HTML의 복제 시점 서식을 보존합니다. JavaScript 동작, SVG 개체, 외부 자산, 지원하지 않는 CSS 변환 등은 복제 대상으로 지원하지 않습니다. 선택 묶음에 처리할 수 없는 개체가 있으면 이유를 표시하고 묶음 전체의 복제를 거절합니다. 필요한 이미지는 먼저 해당 자료에 포함하세요.

### 정렬과 간격 분배

두 개 이상을 선택하고 **정렬·분배**에서 왼쪽·가운데·오른쪽 또는 위쪽·중간·아래쪽을 누릅니다. 기준은 선택한 개체 전체를 둘러싼 범위이며, 슬라이드 중앙에 맞추는 명령은 아닙니다. 회전한 개체는 화면에서 보이는 외곽 사각형을 기준으로 계산합니다.

세 개 이상을 선택하면 **가로 분배**·**세로 분배**를 사용할 수 있습니다. 양 끝 개체를 고정하고 개체 사이 간격을 동일하게 맞춥니다. 공간이 부족하면 개체가 겹칠 수 있으므로 먼저 양 끝의 간격을 넓히세요. 지원하지 않는 변환이나 편집 좌표 범위를 넘는 조합은 전체 명령을 적용하지 않고 안내합니다.

### 레이어 선택·숨김·잠금·순서

오른쪽 **레이어** 목록에서 다른 개체 뒤에 가려진 항목도 선택할 수 있습니다. 항목별 표시와 잠금 버튼으로 숨김·표시 및 잠금·해제를 바꿉니다. **선택 숨기기**·**선택 잠금**은 현재 선택한 개체들에 함께 적용됩니다. 숨긴 개체는 목록에서 다시 표시하고, 잠긴 개체는 잠금을 해제한 뒤 편집하세요.

**맨 앞**·**앞**·**뒤**·**맨 뒤**는 같은 컨테이너에 속한 개체끼리 순서를 바꿉니다. 여기서 컨테이너는 HTML의 같은 부모 요소이며, 서로 다른 컨테이너나 CSS 겹침 범위를 하나로 합치지는 않습니다. 레이어 목록은 슬라이드 전체의 모든 겹침을 바꿀 수 있는 전역 순서표가 아닙니다.

잠금은 드래그·키보드·속성 패널의 실수 방지 기능입니다. 접근 권한 제어가 아니므로 JSON·코드 편집을 통한 명시적 변경까지 금지하지 않습니다. 사용 범위와 업데이트 절차는 [2단계 적용 안내](STAGE2_LINUX_DEPLOYMENT.md)를 참고하세요.

### 이미지 자르기와 Fill/Fit

**이미지**로 추가한 개체를 선택하면 **프레임 맞춤**과 네 방향 **자르기 %**가 표시됩니다. 자르기 값은 원본 가장자리에서 제외할 비율이며 왼쪽+오른쪽, 위쪽+아래쪽의 합은 각각 99% 이하여야 합니다.

- **채우기(Fill)**: 자른 영역의 비율을 유지하면서 프레임을 가득 채웁니다. 프레임과 비율이 다르면 중앙 기준으로 더 잘립니다.
- **맞춤(Fit)**: 자른 영역 전체를 프레임 안에 표시합니다. 남는 여백에는 개체 배경이 보입니다.
- **늘이기**: 자른 영역을 프레임 크기에 맞춥니다. 원본 비율이 달라질 수 있습니다.

**자르기 초기화**는 네 방향 값을 0으로 돌리고 맞춤 방식은 유지합니다. 원본 파일은 바뀌지 않으며 새 이미지로 교체하면 자르기 값은 초기화됩니다. 원본 HTML의 단순 이미지는 **복제** 후 독립 이미지에서 편집합니다. 복잡한 CSS 장식이 포함된 원본은 HTML 스냅샷으로 유지될 수 있습니다.

### 도형과 테두리

**도형** 버튼에서 사각형·원/타원·선·화살표를 선택합니다. 선택 후 종류, 채우기 색/없음, 테두리 색·0~40px 두께·실선/파선/점선을 바꿉니다. 선과 화살표는 테두리 설정으로 표시하며 회전 핸들로 방향을 바꿉니다. 원은 너비와 높이를 같게 설정합니다.

### 그룹과 그룹 해제

사이트에서 추가한 텍스트·이미지·도형을 두 개 이상 선택하고 **그룹** 또는 **Ctrl+G**를 누릅니다. 그룹 내부를 클릭해도 그룹 하나가 선택되며 이동·회전·크기 변경이 함께 적용됩니다. 그룹 크기는 항상 비율을 유지합니다. 개별 내용을 바꿀 때는 **그룹 해제** 또는 **Ctrl+Shift+G**로 풀어 편집합니다.

해제 시 이동·회전·배율을 자식에게 반영해 위치와 외형을 유지합니다. 그룹을 레이어 앞/뒤로 이동한 경우 해제한 자식도 그 위치를 이어받습니다. 그룹 생성·해제 각각은 Undo 한 번으로 되돌립니다. 그룹 복제·붙여넣기와 슬라이드/자료 복제에도 자식과 이미지 원본이 함께 보존됩니다.

중첩은 4단계까지, 내부를 포함해 추가 개체 500개까지 지원합니다. 임의 원본 HTML 컨테이너와 HTML 스냅샷은 그룹 대상에서 제외됩니다. 글자 크기·테두리·위치 제한을 벗어나는 확대 그룹은 해제를 거부하고 그대로 유지하므로 크기를 조정한 뒤 해제하세요.

## 4. 여러 창에서 수정했을 때

동시 공동 편집은 지원하지 않습니다. 다른 창이 먼저 저장하면 충돌을 알립니다. 내 수정 내용을 JSON으로 내려받거나, 내 수정으로 새 버전을 저장하거나, 서버의 최신 내용을 다시 열 수 있습니다. 내 내용으로 저장하면 다른 창의 최신 수정이 현재 화면에서 대체될 수 있지만 기존 revision은 남습니다.

## 5. 파일 관리

자료 카드 또는 편집기에서 ‘파일 관리’를 엽니다. 목록은 서버에 실제 보관 중인 웹 자산이며 ZIP 파일 자체는 남지 않습니다. 용량은 파일 본문·revision·메타데이터 크기의 합이며 디스크 블록 점유량이나 컨테이너 로그 용량은 포함하지 않습니다.

각 파일을 다운로드하거나 전체 웹 원본을 ZIP으로 받을 수 있습니다. 원본 묶음에는 편집 결과가 적용되지 않습니다. 수정된 발표를 내려받을 때는 ‘다운로드 → HTML ZIP’을 사용하세요. 원본 HTML에는 편집용 식별자가 추가되어 최초 파일과 바이트 단위로 같지 않을 수 있습니다.

삭제 버튼은 시스템이 추가 이미지로 기록한 파일 중 사용 참조가 없는 파일에만 활성화됩니다. 원본 파일, 기능 도입 이전 파일, 어느 revision에서든 참조하는 파일은 보호됩니다. 파일을 삭제하기 위해 이전 버전을 임의로 버리지는 않습니다. 큰 자료 전체가 불필요하면 휴지통에서 자료 단위로 완전 삭제하세요.

## 슬라이드 구성·노트·레이아웃·테마

왼쪽 목록에서 장을 클릭하면 현재 슬라이드가 바뀝니다. **Ctrl/Cmd 클릭**으로 여러 장을 선택하고 **Shift 클릭**으로 연속 범위를 선택합니다. 선택한 장을 드래그하거나 아래의 ↑/↓ 버튼으로 이동합니다. 복제하면 선택한 마지막 장 뒤에 원래 순서대로 새 장이 생깁니다. 노트·레이아웃·코드·마스터 연결과 개체도 복사하며 개체 ID는 독립적으로 만듭니다. 모든 장 삭제와 80장 초과는 거부합니다.

슬라이드 목록에 포커스가 있을 때 Ctrl/Cmd+A는 전체 장 선택, Ctrl/Cmd+D는 장 복제, Delete는 장 삭제입니다. ↑/↓는 장 이동, Shift+↑/↓는 범위 선택, Alt+↑/↓는 순서 변경입니다. 캔버스 안의 단축키는 기존처럼 개체를 대상으로 합니다.

캔버스 아래 **발표자 노트**를 열어 입력하면 현재 장에 자동 저장됩니다. 다른 장으로 바로 넘어가도 원래 장에 기록됩니다. 노트는 일반 텍스트이며 직접 편집은 장당 20,000자까지 지원합니다. 기존 원본에서 가져온 더 긴 노트는 읽기 전용으로 전체를 보존합니다. **새 공유·HTML 다운로드·PPTX에는 노트를 기본 제외합니다.** 공유에서 포함을 선택해 게시하면 수신자가 **발표자 노트 보기**로 내용을 읽을 수 있고 다음 게시에도 선택이 유지됩니다. 청중 전용 화면에는 노트가 나오지 않습니다. 포함 여부는 공유/다운로드에서 선택하며, 기존 공유 링크는 다시 게시하기 전까지 이전 정책을 유지합니다.

**레이아웃**에서 표지, 제목과 본문, 제목과 두 단 본문을 선택합니다. 제목·본문은 일반 텍스트 개체처럼 수정하고 이동할 수 있습니다. 레이아웃 적용과 초기화는 연결된 자리표시자의 위치·기본 서식을 설정하며 입력한 텍스트와 다른 개체를 유지합니다. 두 단에서 한 단으로 바꾸면 사용하지 않는 두 번째 본문은 일반 개체로 남습니다. ‘연결 해제’도 개체를 지우지 않습니다. 자리표시자를 삭제하거나 그룹으로 묶으면 해당 역할 연결이 해제됩니다.

가져온 HTML은 자동으로 지우거나 재배치하지 않으므로 새 레이아웃과 겹칠 수 있습니다. 새 빈 장에 레이아웃을 적용하거나 HTML/CSS에서 기존 배치를 정리해 사용하세요. 기존 **마스터**는 공통 배경·브랜드 요소를 관리하고 레이아웃은 제목·본문 자리를 관리합니다.

**테마**에서 배경·본문·강조색과 제목·본문 글꼴을 바꿉니다. 배경은 레이아웃이 연결된 장에, 글꼴·색은 테마에 연결된 문자에 적용합니다. 개별 문자에 따로 지정한 글꼴·색은 유지합니다. 레이아웃 초기화는 해당 텍스트를 기본 테마 서식으로 다시 연결합니다. 글꼴은 편집 PC·서버·PowerPoint PC에도 설치되어 있어야 같은 모습으로 표시됩니다.

왼쪽 썸네일은 저장한 버전의 정적 내용을 보여 줍니다. 원본 스크립트나 3D·애니메이션은 실행하지 않아 실제 발표 화면과 차이가 날 수 있습니다. 편집기 레이아웃·마스터를 PowerPoint의 네이티브 마스터 계층으로 변환하는 기능은 아직 포함하지 않습니다. [5단계 서버 적용·검증 안내](STAGE5_LINUX_DEPLOYMENT.md)를 참고하세요.

## 6. 발표와 공유

‘발표’는 현재 저장 내용을 새 창의 비공개 미리보기로 엽니다. ‘공유’는 현재 저장 버전을 게시합니다. 공개 링크를 가진 사람은 누구나 열 수 있으므로 전달 대상을 확인하세요.

발표 화면은 창 안에 16:9 한 장을 맞추고 하단에 이전·현재 장수·다음·전체 화면을 표시합니다. →·↓·PageDown·Space는 다음 장, ←·↑·PageUp·Shift+Space는 이전 장, Home·End는 첫 장·마지막 장입니다. 입력창과 링크·버튼의 기본 키 동작은 유지합니다. Tab으로 링크·발표 버튼에 이동하고 Enter로 실행하세요. 전체 화면은 브라우저가 허용할 때 사용할 수 있습니다.

공유 후 다시 수정해도 이미 게시한 버전은 그대로입니다. 최신 내용을 공개하려면 다시 게시합니다. ‘공유 종료’나 자료의 휴지통 이동은 기존 링크를 무효화합니다. 상대가 이미 내려받거나 캡처한 파일은 회수하지 못합니다.

### 다른 사이트에 iframe으로 표시하기

자료별 **공유 → iframe 허용 사이트**에 `https://portal.example.com`처럼 사이트 주소를 한 줄에 하나씩 입력하고 **공유 링크 만들기 / 이 설정으로 다시 게시**를 누릅니다. 최대 20개, 전체 주소 길이는 2,048자까지입니다. 경로·쿼리·와일드카드·IPv6 주소는 사용할 수 없습니다. 호스트와 포트를 지정하며, `www`나 다른 하위 도메인은 별도 주소입니다. HTTPS 주소를 권장합니다. HTTP 주소를 허용하면 브라우저 CSP 규칙에 따라 같은 호스트의 HTTPS 접속도 허용됩니다.

해당 사이트의 iframe `src`에는 게시 후 표시되는 **공유 링크**를 사용합니다. 비공개 미리보기·편집·청중 전용 주소에는 이 허용 설정이 적용되지 않습니다. 중첩 iframe이면 바깥쪽을 포함한 모든 부모 사이트가 허용되어야 하며, 삽입하는 사이트 자체의 iframe 제한도 충족해야 합니다.

목록을 비우고 다시 게시하면 외부 삽입을 차단합니다. 공유 종료·만료도 적용되며, 복제 자료에는 허용 사이트를 복사하지 않습니다. 이미 열린 화면을 원격으로 지우지는 않으며 다음 로드부터 변경된 정책이 적용됩니다. 이 설정은 링크 직접 접속을 제한하지 않습니다.

암호 보호 공유는 새 창에서 열어야 합니다. iframe 허용과 함께 사용할 수 없으며, 기존 암호가 있으면 **기존 접근 암호 해제**를 선택해야 합니다. 암호를 유지하려면 iframe 목록을 비우고 공유 링크를 새 창으로 연결하세요.

## 7. 다운로드

HTML은 웹 기능을 최대한 유지합니다. PDF/PPTX는 출력 시점의 정지 화면을 사용합니다. ES module을 쓴 원본은 내려받은 ZIP을 파일 더블클릭으로 열기보다 로컬 HTTP 서버에서 여세요. Studio 내부에서는 로컬·외부 fetch가 모두 차단됩니다. 단순 예제는 index.html만 열어도 사용할 수 있습니다.

HTML ZIP에는 문자·문단·상자 서식과 이를 표시하는 스크립트가 함께 들어 있습니다. PDF와 외형 보존 PPTX는 현재 표시 화면을 이미지로 보존합니다. **편집 가능 PPTX**는 지원되는 문자별 글꼴·크기·색·굵게·기울임·밑줄, 문단 정렬·줄간격·문단 뒤 간격·들여쓰기·글머리표·번호를 편집 가능한 텍스트로 기록합니다. 자동 맞춤을 사용하면 저장 원본값 대신 실제로 축소돼 보이는 글자와 간격을 PPTX에 기록합니다.

4단계 이미지·도형·그룹도 HTML ZIP에서 재생됩니다. 편집 가능 PPTX에는 지원 이미지의 원본과 자르기 값, 네이티브 도형을 기록합니다. WebP는 전체 원본을 PNG로 변환합니다. 웹 그룹은 독립 자식 개체로 풀어 출력하며 PowerPoint의 그룹 계층 자체는 유지하지 않습니다. 그룹 중 지원 불가 개체가 있으면 해당 그룹 전체를 배경에 포함합니다. Linux 업데이트·검증표는 [4단계 적용 안내](STAGE4_LINUX_DEPLOYMENT.md)를 참고하세요.

‘자르기’를 설정했고 실제로 넘치는 글자는 화면과 다른 숨은 문자가 노출되지 않도록 배경 이미지에 포함합니다. 이 텍스트는 PPTX에서 개별 편집할 수 없습니다. 잘리지 않는 지원 텍스트는 계속 개별 편집할 수 있습니다. 글꼴 파일을 PPTX에 포함하지 않으므로 PowerPoint PC의 글꼴 설치 상태, 줄바꿈과 렌더링 차이는 실제 PowerPoint에서 별도로 확인하세요. Linux 서버의 Chromium·한글 글꼴 확인 절차는 [3단계 적용 안내](STAGE3_LINUX_DEPLOYMENT.md)에 있습니다.

출력은 서버당 한 번에 하나만 실행합니다. 다른 작업 중이면 완료 후 다시 시도하라는 안내가 나옵니다. 출력 결과는 30분 후 만료하므로 필요한 파일을 내려받으세요.

## 8. 암호 변경

상단 ‘비밀번호 변경’에서 현재 암호와 새 암호를 입력합니다. 새 암호는 12~128자이며 확인값과 같아야 합니다. 성공하면 현재 창은 로그인 상태를 유지하고 다른 로그인 세션은 종료됩니다. 로컬 무인증 모드에서는 이 버튼을 표시하지 않으므로 서버 환경변수로 초기 암호부터 설정하세요.

## 자주 묻는 질문

**원본 ZIP이 계속 서버에 쌓이나요?** 아니요. 압축 해제 파일과 수정 이력이 쌓입니다. 파일 관리의 용량과 전체 자료 수를 함께 확인하세요.

**이전 버전을 지우면 공간이 줄어드나요?** 현재는 revision 개별 삭제 기능이 없습니다. 복원 가능성을 위해 이력을 유지합니다. 필요 없는 자료 전체를 완전 삭제할 수 있습니다.

**PPTX를 PowerPoint에서 모두 편집할 수 있나요?** 지원하는 글·이미지·도형·표·차트는 개별 편집할 수 있습니다. 실제로 잘리는 글·표, CSS·3D·복잡한 장식은 배경으로 합칩니다. 외형 보존 모드는 전체가 이미지입니다. 실제 PowerPoint에서 수정·저장·재열기와 외형 비교를 검증했으며, 글꼴·줄바꿈·차트 등 일부 렌더링 차이는 남습니다. [검증 결과와 범위](STAGE6_7_VALIDATION.md)를 확인하세요.

**PPTX를 가져오거나 표·차트·효과를 추가하려면?** 자료실의 ‘PPTX 가져오기’에서 변환 경고를 검토한 뒤 자료를 생성합니다. 편집기 상단의 ‘표’, ‘차트’, ‘전환·효과’에서 새 기능을 사용할 수 있습니다. [6·7단계 사용법과 제한](STAGE6_7_LINUX_DEPLOYMENT.md#사용-방법)을 확인하세요.

**자동 백업되나요?** 기본 제공하지 않습니다. 서버 운영자가 별도로 설정해야 합니다.

## 상단 메뉴·표와 차트·링크

상단 **슬라이드·삽입·디자인·파일**을 누르면 해당 도구가 작은 메뉴로 열립니다. Escape로 닫고 원래 버튼으로 돌아갑니다. 글꼴·크기·색은 오른쪽 **서식**, 위치·크기는 **배치**에서 조절합니다. 문단·텍스트 상자·이미지 자르기·도형의 자세한 설정은 서식의 버튼으로 엽니다. 패널 본문은 하나의 스크롤로 이동합니다.

**표·차트**는 셀을 직접 눌러 편집합니다. 선택한 행·열을 삭제하거나 추가할 수 있으며, 스프레드시트에서 복사한 여러 셀을 붙여넣을 수 있습니다. 차트 종류와 계열 색은 선택 도구로 바꿉니다. 표는 최대 20행·10열, 차트는 20개 범주·5개 계열입니다. 큰 데이터 표 안의 스크롤은 유지됩니다.

**링크 · 페이지 이동**은 하나의 요소를 선택한 뒤 링크 버튼으로 설정합니다. 웹 주소(http/https)는 새 탭으로, 이 발표의 슬라이드는 제목이 있는 페이지 목록에서 고릅니다. 저장한 링크는 발표·공유·HTML ZIP에서 작동하며 편집 중에는 요소를 선택합니다. 슬라이드 순서를 바꿔도 같은 페이지로 이동합니다. 연결된 페이지를 삭제하면 이동하지 않으므로 링크를 다시 지정하거나 제거하세요. 공유 화면에는 공유 버전을 다시 게시해야 반영됩니다. 외형 보존·편집 가능 PPTX 모두 웹 주소와 내부 슬라이드 이동을 출력합니다. 삭제된 대상·숨긴 영역·위험 주소는 제외합니다. 3D 변환·마스크·복잡한 자르기는 링크를 제외하고 호환성 안내에 기록할 수 있습니다. PDF 링크는 지원하지 않습니다.

## AI 작성과 Three.js 배경

AI가 만든 발표는 `index.html`, CSS·JS·이미지·글꼴을 같은 폴더에 모아 ZIP으로 가져옵니다. 1920×1080의 `main#stage` 안에 같은 부모를 둔 `section.slide`를 만들고 한 번에 한 장만 표시합니다. 글은 DOM 텍스트로 두어 편집할 수 있게 합니다. [복사용 프롬프트와 설치 방법](AI_AUTHORING.md)에 전체 작성 조건이 있습니다.

Three.js는 **원본 HTML ZIP의 로컬 `.js`**로 포함합니다. CDN·외부 이미지·API뿐 아니라 로컬 파일에 대한 fetch도 차단되므로 기본 도형·절차적 그래픽을 사용하세요. `.gltf`·`.glb`·`.bin`·`.mjs`는 가져오기 지원 파일이 아닙니다. 배경 canvas는 `pointer-events:none`으로 글 선택을 가리지 않게 하고 WebGL 실패·동작 줄이기에 정지 대안을 준비합니다. 임의 3D 모델·카메라의 시각 편집은 지원하지 않습니다.

**HTML/CSS 편집창은 슬라이드 내부 HTML/CSS만 받습니다.** JavaScript·canvas를 붙이는 곳이 아닙니다. 실행 코드를 바꾸려면 원본 묶음을 수정해 새 자료로 가져오세요. HTML 다운로드는 웹 기능을 유지하지만 PDF·PPTX의 3D는 정지 이미지이며 PowerPoint의 편집 가능한 3D 개체로 바뀌지 않습니다.


## 일상 편집 흐름 업데이트

- 홈에서 글꼴·크기·색·정렬, 오른쪽에서 선택한 개체의 위치·크기를 연속 편집합니다. HTML/CSS·JSON·마스터는 파일 → 고급 도구로 이동했습니다. 캔버스 개체 선택의 Tab은 마지막 개체 이후 도구로 빠져나오고 입력창에서는 기본 동작을 유지합니다.
- 자료 가져오기는 여러 ZIP/PPTX 선택과 드롭, 파일별 검사/업로드/완료/실패/재시도를 지원합니다. PPTX는 경고 검토 후 개별 확인합니다. 같은 파일은 중복 가능성을 표시하며 서버가 동일 업로드의 재시도로 자료를 중복 생성하지 않습니다. 독립 사본은 자료실의 복제를 사용하세요.
- 설정 → AI 연결에서 외부 PC 설치/갱신 명령과 프롬프트를 복사합니다. 웹사이트는 외부 PC를 직접 조사하지 않으며 MCP가 실제 보고한 버전·시각·서버/인증/도구/폴더 진단만 표시합니다.
- 파일 → AI 변경 검토는 전후 화면과 문구를 보여 줍니다. 선택한 장과 공통 디자인 변경을 적용하며, 저장본이 바뀌었다면 새 변경안을 요청해야 합니다. 취소는 저장본을 바꾸지 않습니다. 적용 후 버전에서 복원할 수 있습니다.
- 발표 전 점검은 실제 렌더링을 검사하며 자동 수정하지 않습니다. 애니메이션·Three.js·실제 출력 차이는 수동 확인 대상입니다. 발표자와 청중은 별도 창 또는 한 화면 전환으로 사용하며 청중에게 노트를 보내지 않습니다.
- 디자인 → 템플릿은 현재 내용을 지우지 않고 새 독립 자료를 만듭니다. 브랜드는 색·글꼴·로고를 저장해 적용하며 개별 서식을 덮어쓰지 않습니다.
- 새 공유와 다운로드는 노트를 기본 제외합니다. 기존 공유본은 다시 게시 전까지 이전 동작을 유지합니다. 다시 게시 시 노트 제외를 선택하면 기존 링크의 응답도 변경됩니다. 만료·공유 종료는 자산 접근에도 적용됩니다.
- 자료 목록의 업로드/수정과 자료 정보/버전/게시 시각은 서로 구분되며 한국 시간으로 표시합니다. 버전은 최신순이며 5분 내 자동 저장은 접어서 표시하지만 이력을 삭제하지 않습니다. 버전 이름은 사용자가 지정할 수 있습니다.

## 도구 찾기와 AI 수정 요청

- **도구 찾기** 또는 Ctrl/Cmd+Shift+P: 도구·슬라이드 제목을 검색하고 ↑/↓·Enter로 실행합니다. Escape로 닫습니다. 입력창·텍스트 편집·한글 조합 중에는 입력을 우선합니다.
- **전체 슬라이드**: 기존 썸네일을 격자로 보고 장을 선택합니다. 이동 전 편집 내용을 저장하며 충돌이면 현재 초안을 보존합니다.
- **서식 패널 접기**: 상단 서식 버튼 또는 패널 닫기를 누르면 캔버스가 넓어집니다. 상단 메뉴는 필요할 때 열고 Escape로 닫습니다.
- 보고서·강의·제안서는 각각 KPI·분석·실행 과제, 학습 목표·실습·복습, 문제·해결·일정·의사결정 구성을 제공합니다. 대괄호의 입력 안내를 실제 자료로 바꾸세요. 디자인에서 브랜드를 적용하거나 독립 템플릿으로 저장할 수 있습니다.

개체를 선택하고 오른쪽 **선택 개체에 AI 수정 요청**을 누르세요. 상단 말풍선 **수정 요청 목록**에서는 현재 장에 대한 요청도 작성할 수 있습니다. 요청은 저장 당시 버전과 대상에 연결되며 비공개로 보관됩니다. 공유·HTML/PPTX·템플릿·복제 자료에 포함되지 않습니다. 자료당 최대 500개, 요청당 2,000자입니다.

AI 연결의 MCP를 0.4.0 이상으로 업데이트하고 재시작한 뒤, 요청 목록의 프롬프트를 연결된 Codex/Claude Code에 전달합니다. 요청만 작성한다고 AI가 자동 실행되지는 않습니다. AI는 `slides_list_feedback`과 최신 상태를 읽고 기존 변경안으로 제출합니다. **AI 변경 비교**에서 전후를 확인해 선택 적용하거나 취소하세요. 다른 편집이 있으면 최신 상태를 다시 확인합니다. 요청의 ‘이후 수정됨’·‘대상 없음’ 표시를 확인하고, 적용 결과를 검토한 뒤 직접 완료 처리합니다. 다시 열기도 가능합니다. 적용 자체는 기존 버전 기록에 남아 복원할 수 있습니다.

PDF/PPTX 캡처는 종료 시점이 있는 CSS/Web Animations를 마지막 프레임으로 정착시키고 무한 반복은 현재 프레임에 멈춥니다. 임의 JavaScript·canvas·Three.js의 의미 있는 마지막 장면을 자동 판단하지는 않습니다. PPTX 텍스트는 서버에서 사용 가능한 CSS 글꼴 목록의 대체 글꼴을 선택하지만 글꼴을 파일에 포함하지 않습니다. 다른 PC에서의 글꼴·줄바꿈과 복잡한 링크 겹침은 실제 PowerPoint에서 확인하세요.


## 보관함·배치·전체 디자인

상단 **자산 보관함**에서 현재 자료와 공용 보관함을 전환합니다. 여러 이미지·SVG·폰트를 올리고 이름·종류·사용 여부로 찾으세요. 실패한 파일만 재시도할 수 있습니다. 공용 이미지를 삽입하면 현재 자료에 별도 사본이 생깁니다. 사용 장으로 이동하거나 선택한 이미지를 교체할 수 있으며, 원본과 이전 저장 버전의 파일은 삭제가 제한됩니다. 이름 변경은 표시 이름만 바꿉니다.

SVG는 안전한 정적 형태만 받으며 슬라이드 삽입 시 PNG로 변환합니다. 폰트는 샘플 확인·보관·다운로드용으로, 가져오기만으로 슬라이드에 적용되지 않습니다. 온라인 로고는 이름으로 찾고 밝은/어두운 변형을 선택하세요. Google Fonts는 정확한 글꼴 이름과 굵기·기울임을 입력해 조회하며 문자 범위별 파일일 수 있습니다. 온라인 연결 실패 시 파일을 직접 내려받아 업로드할 수 있습니다.

**배치**에서 정렬 기준을 선택 영역 또는 슬라이드로 바꿉니다. 개체 하나는 슬라이드에 정렬됩니다. 스마트 안내선은 드래그 중 가장자리와 중심을 맞추며 Alt로 잠시 끕니다. **상위 개체 선택**으로 감싸는 요소를 고릅니다. 추가한 이미지는 **화면에서 자르기**에서 영역을 끌거나 방향키·크기 막대로 조절하고 적용하세요. 취소하면 현재 이미지는 그대로입니다.

상단 팔레트 **전체 디자인** 또는 오른쪽 **디자인**에서 색·글꼴·제목/본문 크기·모서리를 미리 봅니다. **이 디자인 적용** 전에는 저장하지 않으며 **미리보기 취소**나 Escape로 돌아갑니다. 미리보기 중에는 다른 편집을 잠시 막습니다. 테마에 연결된 요소만 변경하며 개별 서식은 유지합니다. 적용 결과는 파일 → 버전에서 복원할 수 있습니다. 상세 범위는 [패널 비교](OPEN_SLIDE_PANELS.md)를 확인하세요.
