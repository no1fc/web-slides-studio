# open-slide 편집 화면 적용

사용자가 ‘open-slide 화면을 최대한 동일하게’를 선택하여, 기능 참조에 이어 편집 화면을 개편했다. 참조는 [open-slide commit 1f18ab5](https://github.com/open-slide/open-slide/tree/1f18ab5970fa5e68219b8ff1811799d5018122cd)의 **개발용 편집 화면**이다.

## 근거

REA로 `routes/slide.tsx`, `thumbnail-rail.tsx`, `panel/editor-sidebar.tsx`, `panel/panel-shell.tsx`, `notes-drawer.tsx`를 선택 분석했다. 5개 파일 파싱 성공, 실패0. Evidence `ev_d6473583675c7d83cbacf608fe3f2296e428cd5baa2694720e22aa54fbf20ab4`; 상세 범위와 미확인 관계는 [기록](open-slide-ui-evidence.json)에 남긴다.

참조 프로젝트를 별도 임시 디렉터리에서 고정 의존성으로 빌드하고 Node22 컨테이너의 loopback 포트에서 실행했다. `NODE_ENV=development`를 명시한 실제 편집 화면을 Chromium 1366×768로 캡처해 대조했다. 공개 뷰어에서는 편집·노트·속성 버튼이 숨겨지므로 개발 화면과 구분했다. 원본 자료나 운영 인증정보는 참조 프로젝트에 전달하지 않았다.

| 구성 | 참조와 적용 기준 |
| --- | --- |
| 상단 | 48px 한 줄, 가운데 제목, 작은 아이콘 버튼, 주홍 발표 버튼 |
| 슬라이드 목록 | 기본264px, 184px 썸네일, 왼쪽 장 번호, 활성 장 주홍 테두리 |
| 캔버스 | 40px 안쪽 여백, 외곽8px,10px 모서리,16:9 화면 맞춤과 가운데 정렬 |
| 오른쪽 | 기본320px, 서식·배치·레이어, 본문 하나의 스크롤, 접기 가능 |
| 노트 | 전체 편집 영역 아래36px 토글, 장별 노트와 저장 상태 |
| 시각 요소 | 무채색 OKLCH 배경과 주홍 강조, Geist Variable, Lucide 아이콘, 파란 개체 선택선 |

## 기존 동작과의 연결

큰 리본은 슬라이드·삽입·디자인·파일 메뉴 안에서 열도록 바꿨다. 기존 버튼을 이동해 원래 이벤트 처리·검증·저장 경로를 재사용한다. 서식과 위치·크기는 오른쪽 패널에서 조절하며 표·차트·코드·마스터·전환·점검·버전·AI 비교 기능을 보존한다. 메뉴는 Escape로 닫고 키보드 포커스를 돌려준다.

SDLAB의 자동 저장·revision 충돌·발표자/청중 분리·암호/만료 공유는 그대로 사용한다. 참조의 수동 저장 방식이나 소스 마커 기반 AI 편집으로 바꾸지 않았다. 따라서 픽셀 단위 완전 복제나 제품 전체 기능의 동일성을 주장하지 않는다. 자료실과 콘텐츠 자체의 디자인은 이 개편 대상이 아니다.

React/Vite를 SDLAB에 설치하지 않았다. UI 글꼴과 아이콘은 로컬 자산이며, 배포되는 [vendor-notices.txt](../public/vendor-notices.txt)에 open-slide MIT, Lucide ISC/MIT, Geist OFL 고지를 포함한다. UI 글꼴은 발표 자료의 저장 글꼴이나 PPTX 글꼴을 바꾸지 않는다.

검증은 노트북 화면, 한글 입력, 메뉴·패널 포커스, 기존 편집 회귀, 운영 후보 컨테이너로 수행한다. 실제 수치와 배포 여부는 PR 및 인스턴스 검사 기록에 남긴다. 실제 Safari·macOS·스크린리더 실기를 수행하지 않았다면 검증 완료로 표시하지 않는다.
