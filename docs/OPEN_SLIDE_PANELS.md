## 저장과 보안 경계

디자인 미리보기는 저장본을 바꾸지 않는다. 적용 시 기존 revision 충돌 검사와 이력을 사용한다. 미리보기 중 캔버스·자료 전환·전역 편집 단축키를 잠시 막고 패널의 적용·취소와 입력은 유지한다. 원본 글자 크기와 테마 표시 크기를 구분해 취소와 다시 열기 결과를 일치시킨다. 개별로 서식 지정한 텍스트는 테마 크기로 덮어쓰지 않는다. 임의 HTML의 고정 CSS 전체를 테마화하는 기능은 아니다.

자산 API는 관리자 인증과 Origin 검사를 사용한다. 공용 보관함은 공유 링크에 공개하지 않는다. 공용 자산을 자료에 삽입할 때 독립된 파일을 만들고, 원본 또는 저장 이력이 사용하는 파일은 삭제할 수 없다. 표시 이름 변경은 실제 경로를 변경하지 않는다. 같은 이름은 새 이름/건너뛰기로 처리하며 원본을 덮어쓰는 교체 대신 선택한 이미지에 새 자산을 적용한다. 파일 수·용량·경로·심볼릭 링크·형식 검사를 유지한다.

SVG는 스크립트·외부 참조·스타일·애니메이션을 거부하는 제한된 요소/속성만 받는다. 삽입 시 최대 2048px PNG로 변환해 기존 이미지 편집·출력 경로를 사용한다. 폰트는 헤더/내부 범위를 확인하고 브라우저 FontFace로 샘플을 보여 준다. 내장 폰트 파서 전체를 대체하거나 폰트를 자동 적용하는 기능은 아니다.

온라인 가져오기는 관리자 브라우저에서 공개 제공자의 제한된 HTTPS 주소로 수행한다. 서버의 인터넷 차단과 발표 콘텐츠 CSP는 유지한다. SVGL 목록/SVG와 Google CSS2 조회는 실제 Chromium CORS 응답을 확인했다. Google 전체 카탈로그는 브라우저 CORS로 제공되지 않아 정확한 family 이름·굵기·기울임 조회를 사용한다. 반환된 글꼴은 문자 범위별 파일일 수 있으며 화면에 범위를 표시한다. 다운로드 후 로컬 보관하는 방식이므로 외부 제공자의 이용 조건과 각 파일 라이선스가 적용된다.

새 공유본의 노트는 계속 기본 제외다. 포함 선택 후 게시하면 수신자가 ‘발표자 노트 보기’를 눌러 읽을 수 있다. 다시 게시할 때 선택이 유지되고, 제외로 재게시하면 노트 내용이 제공 응답에서도 제거된다. 발표자 도구의 청중 화면에는 포함 선택과 관계없이 노트를 보내지 않는다.

## 지원 차이와 검증

참조에 없는 일반 불투명도/그림자/뒤집기 도구는 추가하지 않았다. 기존 자료의 원본 이미지에는 숫자 설정을 사용하고 새로 추가·복제한 이미지에 시각적 자르기를 제공한다. 영상·임의 파일은 이번 보관함의 삽입 대상이 아니다. 디자인 조합은 여섯 가지이며 원본의 열두 조합을 복사하지 않았다.

PPTX는 글자 간격을 보존한다. PowerPoint의 네이티브 텍스트가 표현하지 못하는 300/500/600/800 굵기는 외형 보존 이미지로 출력하므로 해당 텍스트는 PPTX에서 개별 수정할 수 없다. 400/700 굵기는 기존 편집 가능한 출력 경로를 유지한다.

검증 항목은 부분 서식/IME/실행 취소, 자르기·정렬, 자산 인증·경로·독립 복사·삭제 보호·SVG/폰트 오류, 노트 공유/제외 응답, 디자인 미리보기 무저장·연속 적용·복원·HTML/PPTX 크기 일치, 작은 화면과 키보드 동작이다. 실제 검사 수와 배포 결과는 PR 및 해당 인스턴스 운영 기록에 남긴다. 실제 PowerPoint·macOS/Safari·스크린리더 실기를 수행하지 않았다면 검증 완료로 표시하지 않는다.
