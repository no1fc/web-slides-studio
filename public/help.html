발표 자료, 이렇게 시작하세요.

파일을 가져오거나 빈 자료에서 시작해 편집하고, 발표·공유·다운로드까지 이어갈 수 있습니다. 배치 편집은 넓은 PC 화면을 권장합니다.

빠른 시작지원 파일편집 도구AI·Three.js 작성다운로드문제 해결

처음부터 발표까지, 6단계

보고서·강의·제안서 템플릿으로 시작할 수 있습니다. 여러 ZIP·PPTX를 끌어 놓으면 파일별 검사와 업로드 상태를 표시하며, 실패한 파일만 다시 시도합니다.

  1. 자료실에 로그인합니다. 관리자 암호를 입력하세요. 이 설명서는 로그인 없이 읽을 수 있습니다.
  2. 자료를 준비합니다. 빈 자료 만들기, 자료 가져오기, 폴더로 올리기, PPTX 가져오기 중 하나를 선택합니다. PPTX는 변환 경고를 읽고 변환 결과 가져오기를 눌러야 등록됩니다. 원본 PPTX도 별도로 보관하세요.
  3. 슬라이드를 편집합니다. 왼쪽에서 슬라이드를 선택하고, 가운데의 글·이미지를 클릭해 오른쪽 서식·배치 패널에서 수정하세요. 글은 더블클릭해 직접 입력할 수 있습니다.
  4. 자동 저장을 확인합니다. 상단에 저장됨 · v번호가 표시된 뒤 이동하거나 창을 닫으세요. 이전 내용은 버전 메뉴에서 확인·복원합니다.
  5. 발표하거나 공유합니다. 발표는 비공개 미리보기입니다. 발표 전 점검에서 넘침·이미지·링크·위치를 확인하세요. 공유에서 게시한 버전만 공유 링크로 볼 수 있으며, 만료일과 접근 암호를 설정할 수 있습니다. 편집 후에는 공유 버전을 다시 게시해야 반영됩니다. 공유 종료 시 기존 링크는 무효가 됩니다.
  6. 필요한 형식으로 받습니다. 다운로드에서 HTML ZIP·PDF·PPTX를 선택합니다. 출력 방식별 차이는 다운로드 안내를 확인하세요.

1 MiB는 1,048,576바이트입니다. PDF·구형 PPT·PPTM·DOCX·HWP·KEY는 직접 가져올 수 없습니다. 파일 이름의 확장자만 ZIP이나 PPTX로 바꾸어도 변환되지 않습니다.

HTML ZIP·폴더 준비하기

진입 파일 이름은 소문자 index.html로 지정하세요. ZIP 최상위에 두거나 하나의 상위 폴더 아래에 함께 담습니다. 슬라이드는 .slide 요소 또는 같은 부모 아래의 section 요소로 구성하고, 16:9 · 1920×1080을 기준으로 준비합니다.

presentation/
  index.html
  style.css
  app.js
  images/
    cover.png
  fonts/
    presentation.woff2

HTML에서 자산은 images/cover.png처럼 상대 경로로 연결하세요. 외부 CDN·원격 이미지·글꼴·iframe·API는 격리 정책으로 차단되므로 필요한 자산을 함께 넣어야 합니다.

포함 가능한 파일: .html, .css, .js, .png, .jpg, .jpeg, .webp, .gif, .svg, .ico, .woff, .woff2, .ttf, .otf, .json, .mp4, .webm. 그 외 확장자는 가져오지 않습니다. 숨김 파일·환경파일·심볼릭 링크는 빼고, 분할 ZIP·ZIP64는 사용하지 마세요.

MP4·WebM은 패키지에 포함할 수 있지만 영상 편집이나 모든 출력 형식에서의 재생을 보장하지 않습니다. HTML 파일 하나만 있다면 그 파일을 ZIP으로 묶거나 포함된 폴더를 선택하세요.

PPTX 변환에서 확인할 점

지원되는 글·이미지·기본 도형·표·차트·노트를 웹 편집 요소로 변환합니다. 복잡한 배치·마스터·SmartArt·일부 효과는 그대로 재현되지 않거나 생략될 수 있습니다. 가져오기 전 경고와 가져온 후 각 슬라이드의 내용을 확인하세요.

4:3 자료는 PowerPoint에서 16:9로 바꾸고 배치를 확인한 뒤 PPTX로 저장하세요. 암호화된 자료는 암호를 해제한 사본을 준비해야 합니다. 원본과 똑같은 외형이 필요한 경우 변환 결과를 반드시 비교하세요.

편집기에서 이미지 추가하기

상단 삽입 → 이미지 버튼은 PNG·JPEG·WebP·GIF를 받습니다. HTML 패키지 안의 SVG·ICO와 이미지 추가 버튼의 지원 범위는 다릅니다. 추가한 이미지도 자료의 파일 수·용량 제한에 포함됩니다.

자주 쓰는 편집 도구

글·이미지·도형과 배치

상단 삽입 메뉴에서 글·이미지·도형·표·차트를 추가합니다. 글을 더블클릭하고 일부 문자를 선택하면 해당 부분의 서식을 바꿀 수 있습니다. 오른쪽 서식 → 내용 편집 입력은 전체 평문을 바꾸므로 부분 서식을 유지하려면 직접 편집하세요.

개체를 드래그해 이동하고 핸들로 크기·회전을 조절합니다. Shift·Ctrl·Command와 클릭으로 여러 개체를 선택한 뒤 정렬·분배합니다. 잠긴 개체는 레이어에서 잠금을 해제한 뒤 수정하세요.

표·차트와 링크 · 페이지 이동

표와 차트의 셀을 직접 눌러 입력하고, 행·열을 추가하거나 삭제하세요. 스프레드시트에서 복사한 셀도 붙여넣을 수 있습니다. 차트 종류와 계열 색은 선택 도구로 바꿉니다.

요소 하나를 선택한 뒤 삽입 → 링크에서 웹 주소 또는 슬라이드 목록의 이동 대상을 지정합니다. 발표·공유·HTML에서 작동하며 웹 주소는 새 탭으로 열립니다. 편집 중에는 링크가 실행되지 않습니다. 연결된 슬라이드를 삭제하면 링크를 다시 지정하세요. 두 PPTX 형식에도 웹 주소와 슬라이드 이동을 보존합니다. 복잡한 3D·마스크 영역은 제외될 수 있으므로 출력 파일의 호환성 안내를 확인하세요. PDF 링크는 지원하지 않습니다.

슬라이드·노트·테마·효과

왼쪽 목록에서 슬라이드를 추가·복제·삭제하거나 끌어 순서를 바꿉니다. Ctrl·Command 클릭은 다중 선택, Shift 클릭은 범위 선택입니다.

레이아웃은 제목·본문·두 단 구성을, 테마는 공통 색·글꼴을 지정합니다. 전환·효과는 발표 재생에 적용됩니다. 편집 화면과 PDF는 최종 정지 모습을 보여줍니다.

새 공유와 HTML·PPTX 다운로드는 발표자 노트를 기본 제외합니다. 포함을 선택하면 파일이나 응답을 받은 사람이 읽을 수 있습니다. 기존 공유 링크는 다시 게시하기 전까지 이전 정책을 유지합니다.

도구 찾기·전체 슬라이드·AI 수정 요청

상단 도구 찾기 또는 Ctrl·Command+Shift+P로 도구와 슬라이드 제목을 검색합니다. 위·아래 방향키와 Enter로 실행하고 Escape로 닫습니다. 글 입력 중에는 입력용 키 동작이 우선합니다. 전체 슬라이드에서 한눈에 순서를 확인하고 장을 선택하세요. 상단 서식으로 오른쪽 패널을 접어 편집 공간을 넓힙니다. 상단 메뉴는 Escape로 닫습니다.

선택한 개체의 오른쪽 선택 개체에 AI 수정 요청 또는 상단 말풍선 수정 요청 목록에서 요청을 남깁니다. 요청은 비공개이며 공유·다운로드에는 포함되지 않습니다. 연결된 AI에 목록의 프롬프트를 전달한 뒤 변경안을 비교·선택 적용하세요. 요청 작성만으로 AI가 실행되지는 않습니다. 저장 버전이 달라지거나 대상이 삭제되면 확인 안내가 표시됩니다. 결과 확인 후 직접 완료 처리합니다. AI 연결은 MCP 0.4.0 이상이 필요합니다.

단축키와 이전 버전
  • Ctrl·Command+Z: 실행 취소 / Ctrl·Command+Shift+Z: 다시 실행
  • Ctrl·Command+D: 선택한 개체 복제
  • 방향키: 1px 이동 / Shift+방향키: 10px 이동
  • Tab·Shift+Tab: 캔버스에서 선택한 개체의 다음·이전 개체 선택. 끝에서는 일반 포커스 이동
  • Escape: 진행 중인 드래그 취소 또는 선택 해제

입력창·글 편집 중에는 문자 입력이 우선합니다. 실행 취소는 현재 편집 세션에서 사용하며, 오래된 상태는 파일 → 버전에서 복원하세요. 복원 결과는 새 버전으로 저장됩니다.

발표 화면과 키보드 이동

발표자 화면은 현재 장·다음 장·노트·타이머를 보여 줍니다. 청중 화면 열기로 슬라이드만 있는 별도 창을 띄우면 두 창의 이동을 동기화합니다. 팝업이 차단되면 이 화면으로 발표를 선택하고 Esc로 돌아옵니다. 검은 화면(B), 레이저(L), 전체 화면 버튼을 사용할 수 있습니다. →·↓·PageDown·Space는 다음 장, ←·↑·PageUp·Shift+Space는 이전 장, Home·End는 첫 장·마지막 장입니다.

Tab으로 링크·버튼에 이동하고 Enter로 실행합니다. 입력창·링크·버튼의 기본 키 동작은 유지합니다. 전체 화면은 브라우저가 허용할 때 사용할 수 있습니다.

파일 관리와 고급 편집

파일 관리에서 자산과 용량을 확인하고 웹 원본을 내려받을 수 있습니다. 사용 중인 파일과 이전 버전이 참조하는 파일은 삭제가 제한됩니다.

파일 → 고급 도구의 HTML/CSS·JSON·마스터는 구조를 직접 다루는 고급 도구입니다. 변경 전에 버전과 다운로드 사본을 확보하세요. Three.js 배경과 원본이 제공하는 장면은 유지하지만 임의 3D 모델·카메라의 시각 편집은 지원하지 않습니다.

AI로 만들고, 여기서 편집하세요

설정 → AI 연결에서 기존 서버 연결과 변경안 검토를 안내합니다. 별도 파일 제작은 AI에게 아래 작성 조건을 전달해 HTML ZIP을 만든 뒤 자료 가져오기로 가져옵니다. 대괄호를 채우고, 완성한 자료에서 글 수정·저장·발표까지 확인하세요.

복사해서 쓰는 AI 작성 프롬프트

아래 입력칸을 클릭한 뒤 Ctrl·Command+A로 전체 선택하고 Ctrl·Command+C로 복사하세요. 대괄호는 AI에 붙여넣은 뒤 바꿉니다.

Three.js·애니메이션을 사용할 때

Three.js는 원본 HTML ZIP에 로컬 .js 라이브러리로 포함합니다. 기본 도형·절차적 그래픽을 사용하세요. 외부 CDN·원격 자산·iframe·worker와 로컬·외부 fetch는 차단됩니다. .gltf·.glb·.bin·.mjs는 가져오지 않습니다.

글은 canvas가 아닌 HTML 텍스트로 남기고 장식 canvas에는 pointer-events:none을 적용합니다. WebGL 실패·동작 줄이기 설정에서도 내용을 읽을 수 있는 정지 대안을 두세요. #bg 또는 canvas[data-background]는 배경 표시 설정에 연결됩니다. data-scene 장면은 원본 코드에서 구현해야 하며 임의 3D 모델·카메라의 시각 편집은 지원하지 않습니다.

HTML/CSS 편집창은 슬라이드 내부 HTML/CSS만 받습니다. JavaScript·canvas를 붙일 수 없습니다. 실행 코드를 바꾸려면 원본 묶음을 수정해 새 자료로 가져오세요. PDF·PPTX의 3D는 정지 이미지입니다.

Codex·Claude Code 스킬과 MCP 연결

web-slides-author 스킬은 작성자·디자이너·검수자 순서로 발표를 만듭니다. MCP를 연결하면 AI가 자료 목록과 현재 버전을 읽고, 허용된 ZIP을 가져오거나 한 장을 수정할 수 있습니다. 변경 충돌 시에는 최신 상태를 다시 읽습니다.

설정 → AI 연결에서 외부 PC의 운영체제와 Codex 또는 Claude Code를 고릅니다. 기존 서버에 연결할 때는 외부 PC에 연결 도구만 설치하며 웹 서버나 Docker를 다시 설치하지 않습니다. AI 작성·스킬·MCP 설치 안내 ↗에서 명령과 지원 범위를 확인하세요. 암호값은 대화·발표에 넣지 말고 비공개 암호 파일로 연결합니다.

다운로드 형식 고르기

HTML ZIP
웹 발표용입니다. 자산을 함께 보관합니다. 단순 자료는 index.html을 열고, Three.js 등 ES module을 쓰는 자료는 압축을 푼 폴더를 로컬 HTTP 서버로 여세요.
PDF
16:9 정지 이미지로 출력합니다. 문서 안의 글 검색·선택은 지원하지 않습니다.
PPTX · 외형 보존
각 슬라이드를 하나의 이미지로 넣고 지원 링크 영역을 보존합니다. 외형을 우선할 때 선택하며 글·도형을 개별 편집할 수 없습니다.
PPTX · 편집 가능
지원되는 요소를 편집 가능한 개체로 출력합니다. 복잡한 CSS·3D 등은 배경 이미지가 됩니다. 서버에 없는 첫 글꼴은 CSS 목록의 사용 가능한 다음 글꼴을 선택합니다. 글꼴 파일은 포함하지 않습니다. 글꼴·줄바꿈·효과는 PowerPoint에서 확인하세요.

가져오기와 다운로드의 지원 형식은 다릅니다. PDF로 내려받을 수 있어도 PDF를 다시 가져와 편집할 수는 없습니다.

막혔을 때 확인하세요

“index.html 하나를 포함해 주세요” 또는 “자산 누락”

파일 이름과 폴더 구조를 확인하세요. 연결된 이미지·CSS·JS·글꼴을 함께 압축하고 HTML의 상대 경로가 실제 파일 경로와 일치하는지 확인합니다.

업로드 용량·파일 수 제한을 넘었습니다

이미지·영상을 줄이고 사용하지 않는 파일을 제거하세요. ZIP 크기와 압축 해제 크기는 별도로 제한합니다. 큰 발표는 여러 자료로 나누세요.

그림·배경·글꼴이 원본과 다릅니다

외부 주소에 의존하는 자산을 로컬 파일로 포함하세요. PPTX라면 가져오기 경고를 확인합니다. 모든 HTML 프레임워크·PowerPoint 기능이 자동으로 재현되지는 않습니다.

저장이 안 되거나 다른 창의 변경 알림이 나옵니다

저장 상태와 오류 안내를 먼저 확인하세요. 공동 편집은 지원하지 않으므로 같은 자료를 편집하는 다른 창을 정리하고, 충돌 안내에 따라 최신 버전을 확인합니다. 저장 실패 상태에서 창을 닫지 마세요.

수정한 내용이 공유 링크에 보이지 않습니다

자동 저장은 개인 자료를 갱신합니다. 공유 화면에서 최신 버전을 다시 게시해야 링크에 반영됩니다. 휴지통 이동 또는 공유 종료 후에는 기존 링크가 무효가 됩니다.

삭제한 자료를 되찾고 싶습니다

사이드바 휴지통에서 복원하세요. 완전 삭제한 자료는 앱에서 복원할 수 없으며 별도 서버 백업이 필요합니다. 자동 백업은 기본 제공되지 않습니다.
